Resolving Question III.5 of Stepanov–Herrmann–Guhr (arXiv:2104.08966v1, p. 7): the top-eigenvector weight gap occurs exactly above sigma = c

Haobo Ma, Wenlin Zhang

论文

相关矩阵描述若干量如何共同变化，但它放大最强的方向，未必最接近所有分量同步变化的方向。Haobo Ma 与 Wenlin Zhang 研究给定相关性的平均水平与离散程度，何时能在所有充分大的维度中实现这种错位。对于 Stepanov、Herrmann 和 Guhr 留下的正均值区域，他们的答案是：离散程度必须严格大于均值。

相关矩阵是对角元为一、特征值非负的实对称矩阵。非对角元表示两两相关性，其均值记为 c，标准差记为 σ。特征向量是矩阵只作伸缩的相互垂直方向，特征值给出伸缩倍数。参照方向取各坐标相等、为正且长度为一的向量；特征向量与它的内积平方称为权重，所有权重之和为一。所求权重差要求：无论怎样选取正交归一特征基，每个最大特征值对应向量，都有另一个基向量的权重严格超过它。只找到一种合适的基并不够。

此前三位作者已分别确定一些存在区与不可能区，中间留下了问题 III.5。本文作者解决该剩余区域，并扩展到全部允许的固定参数对。“最终存在”指固定 c、σ 后，有一个依赖于参数的维数门槛，此后每个整数维数都能找到精确满足这两个参数的例子。完整条件是 0 ≤ c < 1/2、σ > c 且 c² + σ² < 1。这是存在性结论，并非具有这些参数的每个矩阵都有权重差。

不可能性的证明把元素平均值与谱信息联系起来。每个特征值减一后，总和为零；平方和记录相关性的均值和方差，加权平均则记录正均值。权重差迫使最高方向的权重小于一半，因此该加权平均不超过两个最大中心化特征值的平均。这两个值必须够大，其余值又须抵消它们的和。由此得到平方和的下界，推出任何有限维例子都必须有 σ > c。特征值非负另行排除了 c ≥ 1/2。作者还证明，若 c > 0 且 σ ≤ c，最大特征方向唯一，权重超过一半。

存在性证明把坐标分成两组，将正倍数的单位矩阵与两个正系数外积相加：一个来自全一向量，另一个来自两组符号相反的向量。这保证正定性，并使同组、跨组相关性各自恒定；Roustant 与 Deville 此前研究过此类分块矩阵。作者选择组的比例，在组大小取整后调整系数，使 c、σ 仍精确等于目标。只有两个特征方向具有非零权重。参数使参照方向的加权特征值低于两者中点，故较大特征值的权重小于一半，较小者则大于一半。

具体例子有十六个坐标，分成十二个与四个两组。同组不同坐标间的相关性为 11/12，跨组为 −5/12，均值为 23/60，方差为 32/75。两个非零权重分别是 3/7 与 4/7，较小权重对应较大特征值，其余权重全为零。这展示了“放大最强”与“最接近同步变化”确实不是同一回事。

重特征值很重要，因为旋转基可以把投影集中于一个向量，也可以分散到整个特征空间。作者的准确判据比较最高特征空间的总投影权重与各较低特征空间的每维平均权重。在圆周边界 c² + σ² = 1，相关矩阵只能是带符号的秩一矩阵，普遍权重差恰在 c < 0 时成立。这些有限维例子不违背最终分类：固定负均值在维数增大后会与半正定性冲突。零均值时，每个固定的 0 < σ < 1 都有充分大维度中的构造。

这些结论有文中书面证明。所报告的有限计算只检验选定恒等式与例子，不能代替关于所有充分大维度的论证。文中声明的 Lean 证据覆盖问题 III.5 剩余区域内的等价结论；完整分类、特征空间判据、边界及其他推论有另外的书面证明，不在该声明的形式化范围内。本文准确刻画均值与离散程度何时允许这种方向错位，但没有分类每个较小维度。此前提出的偏度、峰度等高阶矩改进也未在本文处理。
